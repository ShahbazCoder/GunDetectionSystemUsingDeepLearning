## 📖 About The Project

The increasing incidence of armed threats in sensitive public locations highlights the need for intelligent surveillance. Traditional CCTV monitoring depends heavily on continuous human observation, leading to fatigue and delayed responses. 

This project is a real-time gun detection system that utilizes the **YOLOWorld (yolov8s-worldv2)** object detection model. It features a robust Flask-based AI backend for live video stream inference and a modern React–TypeScript web interface for real-time monitoring, providing automated threat alerts, bounding box visualization, and detection logging.

## ✨ Key Features

* **Real-Time Inference:** Continuous processing of webcam or CCTV surveillance feeds.
* **Open-Vocabulary Detection:** Configured to identify weapon-related classes (gun, pistol, rifle, shotgun, revolver) without requiring custom dataset retraining.
* **Live Threat Dashboard:** User-friendly web interface providing instant visual feedback, bounding boxes, and confidence scores.
* **System Monitoring:** Automated detection logging and model health tracking.
